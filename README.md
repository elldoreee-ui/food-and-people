# food & people — рецепты

Каталог рецептов из телеграм-канала [@vladafoodpeople](https://t.me/vladafoodpeople)
за 2 сентября 2026 года. Тексты приведены дословно.

## Как выложить на GitHub Pages

1. Создайте репозиторий на github.com (например, `food-and-people`).
2. Загрузите в него содержимое этой папки: `index.html`, `README.md` и папку `img`.
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)` → Save.
4. Через минуту сайт будет доступен по адресу
   `https://<ваш-логин>.github.io/food-and-people/`.

Ссылка на конкретный рецепт выглядит так:
`https://<ваш-логин>.github.io/food-and-people/#/r/511` — её можно отправлять кому угодно.

## Что внутри

- `index.html` — весь каталог и все рецепты в одном файле, без сборки и зависимостей
- `img/` — фотографии рецептов, `thumb/` — превью каталога, `strip/` — лента наверху (всё WebP)
